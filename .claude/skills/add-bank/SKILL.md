# 新增題庫／補題

## 1. 先確認

- **新題庫還是補題？** 使用者沒說清楚就問。補題要問加到哪個 `banks/*.js`。
- **id**：新題庫用英文小寫加連字號（例：`tabf-derivatives-21`），先看 `index.html` 最下面的清單，不可跟現有的重複。
- 原題有附答案就照抄；沒附答案才自己判斷，並記下題號。

## 2. 題目格式

新題庫：新增 `banks/<id>.js`，格式照 `banks/ifrs-derivatives.js`：

```js
registerBank({
  id: "<id>",            // 之後不能改，紀錄是用它存的
  title: "<題庫名稱>",
  desc: "<一句說明>",
  questions: [
    {q: "題幹", o: ["選項1", "選項2", "選項3", "選項4"], a: 2, e: "解析"},
  ]
});
```

- `o`：2～6 個選項，不要自己加 ①②③④（畫面會自動編號）
- `a`：正確答案是第幾個選項，**從 1 開始算**
- `e`：每題都要有解析；原題沒附就自己寫，說明為什麼對、其他選項錯在哪
- 題目順序照原本給的，不要刪題、合併或重排
- 字串裡的雙引號要跳脫（`\"`），換行用 `\n`
- 一次很多題時分批寫，每批寫完核對題數

## 3. 絕對不要

- **補題只能加在 `questions` 最後面**，不可在中間插入或刪除——星等與收藏是用題目位置記的，會全部錯位
- 不可改現有題庫的 `id` 或 `storageKey`（舊紀錄會找不到）
- 不要改 `index.html` 的程式或 `test.js`

## 4. 接上網站（新題庫才需要）

- `index.html` 最下面的題庫清單加一行 `<script src="banks/<id>.js"></script>`，放在最後一個題庫後面
- `README.md` 的題庫表格加一列（檔案、題庫名稱、題數）；補題則更新該列題數

## 5. 驗證

跑 `node test.js`，要印出「OK：所有規則測試通過」才算完成。失敗就照錯誤訊息修題庫檔（`bad question <id> <題號>` 指出哪題格式錯）。

## 6. 回報

- 題數（原題幾題、寫進去幾題，要一致）
- 自己判斷答案或自己補寫解析的題號，請使用者核對
- 不要 commit，除非使用者要求
