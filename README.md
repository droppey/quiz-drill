# 刷題網站

一進站先選題目庫，再選範圍（全部／只刷收藏／只刷 ≥N 星）作答。

- 先完整作答一輪 → 交卷 → 顯示答對/答錯與錯題檢視（含解析）
- 只重做錯題，重複到全部答對
- 每題可標 ★ 星等（0–5）與 ♥ 收藏；交卷時答對 +1 星、答錯 −1 星
- 進度與標記依題庫分開存在瀏覽器（localStorage）

### 新增題庫

1. 在 `banks/` 新增一個檔案，例如 `banks/xxx.js`：

```js
registerBank({
  id: "xxx",               // 唯一代號（也用於儲存紀錄，之後不要改）
  title: "題庫名稱",
  desc: "簡短說明",
  questions: [
    {q: "題幹", o: ["選項1", "選項2", "選項3", "選項4"], a: 2, e: "解析"},
  ]
});
```

2. 在 `banks/index.js` 的 `BANK_FILES` 加上 `"xxx.js"`。
